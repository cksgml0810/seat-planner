# 자리 배치 (Classroom Seat Planner)

교탁을 기준으로 교실 자리를 배치하는 웹 프로그램입니다. 설치할 필요 없이 **`index.html`을 더블클릭**하면 브라우저에서 바로 열립니다. 인터넷이 없어도 동작합니다.

## 사용 방법

1. **학생 명단**
   - **엑셀 업로드**: `학번`·`이름` 열이 있는 .xlsx / .xls / .csv 파일을 올리면 자동으로 인식합니다. (양식 파일 내려받기 제공)
   - **번호로 만들기**: 예) 시작 1, 끝 31, 결번 `22` → 1~31번 중 22번을 뺀 30명
   - **직접 입력**: `1 홍길동`처럼 한 줄에 한 명씩 붙여넣기
2. **교실 형태**: 프리셋(5열 7행, 6열 5행 짝/개별 등)을 고르거나 열·행 수와 책상 묶음(개별 / 2인 짝 / 3인)을 정합니다.
   - **좌석 편집**을 켜면 자리를 클릭해 빈자리(사용 안 함)로 만들고, 열 사이 버튼으로 책상을 붙이거나 띄울 수 있습니다.
3. **자리 섞기**를 누르면 무작위로 배치됩니다.
   - 자리를 끌어서 놓거나, 두 자리를 차례로 클릭하면 서로 바뀝니다.
   - 자리의 🔒 버튼으로 고정하면 다시 섞어도 그 자리는 그대로 유지됩니다.
4. **인쇄** / **엑셀** 저장. 학생 시점(교탁 위)과 교사 시점(교탁 아래)을 바꿀 수 있습니다.

## 세부 설정

같이 앉힐 학생, 떨어뜨릴 학생, 앞자리(1~3째 줄) 지정 학생, 직전 짝 피하기 설정을 할 수 있습니다.
화면과 인쇄물에는 표시되지 않으며, 왼쪽 아래의 작은 점을 클릭하거나 **Option(Alt) + Shift + S** 로 엽니다.

## 데이터

- 모든 데이터는 사용하는 컴퓨터의 브라우저에만 저장되며 외부로 전송되지 않습니다.
- 다른 컴퓨터로 옮기려면 왼쪽 아래 **설정 파일 저장** → 다른 컴퓨터에서 **불러오기**.
